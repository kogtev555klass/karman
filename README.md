# Карман

Пробная версия для быстрого ввода расходов. Деньги хранятся целым числом копеек. Примеры в журнале вымышлены, а сохранённые операции остаются в хранилище браузера на устройстве.

## Запуск на Windows

Откройте PowerShell в папке проекта, выполните `node preview.mjs` и откройте [форму](http://127.0.0.1:4173/karman/). Для этой команды нужен Node.js. Чтобы остановить просмотр, нажмите Ctrl+C в PowerShell.

## Публикация и запуск на iPhone

Загрузите исходники в открытый репозиторий GitHub. В **Settings → Pages** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. После публикации GitHub покажет ссылку на приложение.

Откройте ссылку в Safari, выберите **Поделиться → На экран «Домой» → Открыть как веб-приложение → Добавить**. Откройте «Карман» со значка и дождитесь надписи **«Офлайн готов»**.

Введите **250** и нажмите **«Сохранить расход»**. Проверьте запись в **«Операциях»**. Засеките время от нажатия на значок до сохранения. Затем включите авиарежим, закройте приложение, откройте его со значка и сохраните ещё один тестовый расход. Проверьте, что обе записи видны в журнале.

## Обновление

При обновлении исходников увеличьте номер версии кэша в `sw.js`. Откройте приложение по сети, чтобы загрузилась новая версия. Закройте его и вкладки с ним, затем откройте снова по прежнему адресу. Проверьте, что тестовые записи на месте.

## Копия

В «Операциях» нажмите **«Скачать копию»** и сохраните файл JSON в «Файлы» на iPhone или в удобную папку на компьютере. Экспорт содержит все расходы на этом устройстве. Восстановление из файла появится на этапе 3. До его проверки используйте вымышленные суммы.
